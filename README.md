# High Prospective Clients

Serious inbound prospects from networking, Chamber of Commerce, referrals, and direct outreach — higher value than demo/prospect sandboxes.

**Live preview (Clearwater Dentist rebuild):** https://knight-logics.github.io/High-Prospective-Clients/

Each client folder contains:

- **AUDIT.md** — Full pros/cons audit (site, SEO, performance, schema, ads, social, GBP)
- **MEETING-PREP.md** — Questions and automation discovery for on-site visits
- **rebuild/** — Custom static site replica + `npm run serve` locally on port 3457
- **technical/** — Optional raw scans (schema exports, DNS, etc.)
